# Model Selection

<!-- END GENERATED: profile -->

Use this skill when choosing a model or reasoning effort. Classify the task by
its dominant type, estimate its difficulty, and choose the lowest-cost model
with enough capability. Use speed as a tie-breaker when it matters. For mixed
tasks, use the lowest required capability or split the work.

## Reasoning Effort

Choose the lowest effort likely to complete the task reliably. Use lower effort
for bounded extraction, classification, and broad parallel work. Use higher
effort when judgement, incomplete evidence, or consequence demands it. Do not
compensate for a poor model choice by increasing effort.
